01 / PRINCÍPIO

Um dashboard pessoal não precisa de uma plataforma inteira por trás.

Seu servidor.
Seus dados.
Sua interface.

FILOSOFIA

O DashLab foi reduzido ao essencial: um frontend expressivo, uma API Go pequena e um único arquivo SQLite. A landing vive na borda; sua instalação continua dentro de casa.

02 / RECURSOS

Menos infraestrutura.
Mais controle.

Construído para um proprietário, vários dispositivos e um homelab de verdade.

01
⌘

Workspace livre

Organize aplicações, widgets e seções em um canvas ajustável. Desktop e celular mantêm layouts próprios.

02
⌁

Métricas locais

CPU, memória, rede e discos consultados no Prometheus sem expor seu servidor de métricas ao navegador.

03
◉

Status dos serviços

Latência e disponibilidade dos seus aplicativos verificadas pela API dentro da mesma rede do homelab.

04
◇

Identidade própria

Wallpaper, logo, favicon, cores, opacidade, tipografia e comportamento mobile configurados na interface.

05
▣

PWA instalável

Instale como aplicativo no desktop, Android ou iOS, com manifesto e identidade derivados do dashboard.

06
●

Estado portátil

Configuração e imagens persistidas em um volume SQLite simples de copiar, inspecionar e restaurar.

04 / INSTALAÇÃO

Do clone ao painel
em poucos comandos.

  1. 01
    Clone o projeto

    Baixe o código no host em que o Docker está disponível.

  2. 02
    Configure o ambiente

    Informe o Prometheus e os seletores correspondentes ao seu node_exporter.

  3. 03
    Suba os containers

    A API cria o banco SQLite e o dashboard inicial automaticamente.

dashlab / bash
$ git clone https://github.com/ferforastieri/dashlab
$ cd dashlab
$ cp .env.example .env
$ docker compose up -d --build

# interface disponível em
http://seu-servidor:3000
